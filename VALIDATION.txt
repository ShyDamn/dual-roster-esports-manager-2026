English
The 223 assertions above ran against isolated game/save copies. Production DLLs
exclude integration harnesses; the test loader requires a marked separate Save root.
The 366-day run uses the native calendar and real scheduled Major, native player/AI
match-result paths and financial operations. Controlled fixture contracts/budgets/ERS
enable unattended execution; these preparations are not gameplay features. A fresh
process reloaded the resulting career and reconciled both budgets, ledgers and report.
The test does not guarantee a prize-winning placement for both rosters.

Coverage includes both email entry orders, persistent refusal, unavailable-roster
refusal, real native transfers/academy closure, independent travel/prizes/stickers,
read-only report reconciliation and corrupt attribution handling. Windows PowerShell
5.1 update checks cover checksums, fixed paths, actual overwrite rollback, interrupted
recovery and preservation of external edits. A clean full-package install and repair
were verified separately. The Steam SDK subscription/install-folder probe succeeded. Native-rendered report
frames were inspected in Russian and English at 1280x800 and 1920x1080.

Limitations / Ограничения
One year and one controlled real Major are regression evidence, not proof for every
career, future game build, multi-season scenario or other mod combination. Missing
native financial history is not reconstructed. Unknown game builds require a new
tested compatibility package; the prelauncher does not generate game bindings.
